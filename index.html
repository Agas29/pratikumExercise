Dokumentasi Singkat Cara Menggunakan API Estimasi Biaya

API ini digunakan untuk menghitung estimasi biaya konsumsi kegiatan berdasarkan jumlah peserta dan jenis konsumsi.

1. Alamat Endpoint API

[TEMPEL_URL_AZURE_FUNCTION_KAMU_DI_SINI]

2. Parameter yang Diperlukan

  • jumlah (Integer): Jumlah peserta kegiatan (contoh: 40)
  • jenis (String): Pilihan berupa snack, makan, atau lengkap

3. Contoh Format Pemanggilan URL

[TEMPEL_URL_AZURE_FUNCTION_KAMU_DI_SINI]?jumlah=40&jenis=snack
